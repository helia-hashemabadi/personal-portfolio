# Personal Portfolio

A personal portfolio website built with HTML and CSS to showcase my profile, skills, projects, and contact information.

## Live Demo

[View Portfolio](https://helia-hashemabadi.github.io/personal-portfolio/)

## Features

- Personal introduction
- Skills section
- Project showcase
- Contact information
- Responsive design
- Hover effects and smooth scrolling

## Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries
